Privacy Policy

Last updated: July 2026

The short version

ChronoKanban has no server and no user accounts. Your boards, tasks, and everything on them are stored only in your own browser, and stay there unless you explicitly turn on one of the optional sync features described below. There is no backend that could see, log, or sell your data, because there is no backend at all.

Data stored locally in your browser

By default, all of your data — boards, buckets, tasks, categories, attachments, and preferences — is stored in your browser's local storage (IndexedDB and localStorage) on your own device. It is never transmitted anywhere. Clearing your browser's site data for ChronoKanban deletes it permanently, which is why the app periodically reminds you to back up.

Export / Import lets you download or upload a JSON snapshot of your data yourself. This is a manual, local file operation — nothing is sent over the network.

Auto-sync folder (optional, local only)

If you turn this on, ChronoKanban writes a backup file to a folder on your own computer that you choose, using your browser's File System Access API. This is local disk access only — no network request is involved, and no third party is ever contacted.

Google Drive sync (optional)

If you choose to connect Google Drive sync, ChronoKanban requests access to a single, narrow Google scope (drive.file). This scope only ever grants access to files the app itself creates, or to a specific existing file you deliberately choose through Google's own file picker (used for the "join a shared file" option) — it does not grant access to the rest of your Google Drive.

  • The only data accessed or stored is a single JSON file containing your own ChronoKanban board data, kept in your own Google Drive account.
  • Your Google access token is held only in your browser's memory for the current session — it is never written to disk, never stored by ChronoKanban, and never sent to any server operated by us (there is none). It is used solely to make direct calls from your browser to Google's own Drive API, and it expires automatically after about an hour.
  • No one — including the developer — has any way to see the contents of your Drive file or your task data through this feature. There is no logging, analytics, or backend processing of this data.
  • You can disconnect at any time from within ChronoKanban's settings, and independently, fully revoke the app's access from your own Google Account at myaccount.google.com/permissions.

ChronoKanban's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Anonymous usage counting

ChronoKanban uses a privacy-focused, cookieless page-view counter (GoatCounter) to see whether the app is getting any use at all. It records anonymous, aggregate visit counts only — no personal data, no device fingerprinting, no cross-site tracking, and nothing that identifies you individually. This is entirely separate from, and never linked to, your board data or any Google account.

Children's privacy

ChronoKanban is not directed at children under 13, and does not knowingly collect data from them.

Changes to this policy

If this policy changes, the "Last updated" date above will change with it. Meaningful changes will also be reflected in the app's own How-to page.
