Privacy Policy

Last updated: August 2026

The short version

ChronoKanban Teams is the collaborative sibling of the original ChronoKanban — a privacy-first, individual app that deliberately keeps everything in your own browser with no server at all. Teams was built for the opposite need: sharing a board and working on it together in real time. That means it necessarily works differently. When you join a board, its contents — boards, buckets, tasks, categories, and attachments — are shared with everyone else on that board through a server that is run by whoever set up your board, not by ChronoKanban's developer, who operates no server and has no access to your data. Access is protected by a shared board password sent over an encrypted connection.

Your board and the collaboration server

Your board data is transmitted to and stored on the collaboration server operated by whoever set up your board (the "operator"). They control that server, its contents, and how long the data is kept — ChronoKanban's developer has no server and no access to any of it, and cannot see, log, or recover your board.

  • Access is guarded by a single shared board password, sent over an encrypted (HTTPS/WSS) connection. Anyone who has the password has full read and write access to the board — there are no individual user accounts, and no per-person permissions.
  • A copy of the board is also cached in your own browser (IndexedDB and localStorage) so it keeps working offline; local changes sync back to the server when you reconnect.
  • Any privacy questions about how a specific board's data is stored, retained, or secured are ultimately a matter for that board's operator, since they run the server it lives on.

Data cached in your browser

Your preferences, the remembered board password, and a working copy of your board are kept in your browser's local storage (IndexedDB and localStorage) on your own device. Clearing your browser's site data removes this local copy; on a shared board it re-syncs from the server the next time you connect and re-enter the password.

Export / Import lets you download or upload a JSON snapshot of your board data yourself. This is a manual, local file operation — the file is created in your browser and nothing is sent to any third party.

Auto-sync folder (optional, local only)

If you turn this on, ChronoKanban writes a backup file to a folder on your own computer that you choose, using your browser's File System Access API. This is local disk access only — no network request is involved, and no third party is ever contacted.

Google Drive sync (optional)

If you choose to connect Google Drive sync, ChronoKanban requests access to a single, narrow Google scope (drive.file). This scope only ever grants access to files the app itself creates, or to a specific existing file you deliberately choose through Google's own file picker (used for the "join a shared file" option) — it does not grant access to the rest of your Google Drive.

  • The only data accessed or stored is a single JSON file containing your own ChronoKanban board data, kept in your own Google Drive account.
  • Your Google access token is held only in your browser's memory for the current session — it is never written to disk, never stored by ChronoKanban, and never sent to the collaboration server or to any server operated by the app's developer (who runs none). It is used solely to make direct calls from your browser to Google's own Drive API, and it expires automatically after about an hour.
  • No one — including the developer — has any way to see the contents of your Drive file or your task data through this feature. There is no logging, analytics, or backend processing of this data.
  • You can disconnect at any time from within ChronoKanban's settings, and independently, fully revoke the app's access from your own Google Account at myaccount.google.com/permissions.

ChronoKanban's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Anonymous usage counting

ChronoKanban uses a privacy-focused, cookieless page-view counter (GoatCounter) to see whether the app is getting any use at all. It records anonymous, aggregate visit counts only — no personal data, no device fingerprinting, no cross-site tracking, and nothing that identifies you individually. This is entirely separate from, and never linked to, your board data or any Google account.

Children's privacy

ChronoKanban is not directed at children under 13, and does not knowingly collect data from them.

Changes to this policy

If this policy changes, the "Last updated" date above will change with it. Meaningful changes will also be reflected in the app's own How-to page.
